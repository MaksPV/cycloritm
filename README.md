# Cycloritm (Циклоритм)

DSL и движок для циклических расписаний.

## Что это

Cycloritm описывает повторяющиеся процессы (маршруты, смены, дежурства) как шаблоны-циклы, а на выходе выдаёт плоский список событий:

## Зачем

- Отделить расписание от кода приложения: правила живут в отдельных файлах.
- Упростить жизнь разработчикам ПО.
- Задать стандарт описания циклических процессов.
- Возможность подключить этот DSL в популярные ЯП.
- Безопасность: валидация ловит неизвестные события точек и неопределённые переменные до генерации расписания.

## Как устроено

Ядро - Rust, чтобы любой мог встроить его в своё приложение.

## Статус

В процессе проектирования

### Задачи (примерные)

- Разработать стандарт
- Разработать примеры циклических файлов
- Разработать ядро, которое будет принимать на себя все рассчёты
- Создать CLI интерфейс
- Создать интеграции в Python, Kotlin
